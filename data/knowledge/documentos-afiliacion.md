# Documentos requeridos para afiliacion

Documentos base para persona natural:

- Documento de identidad.
- Soporte de ingresos.
- Certificados complementarios segun el producto o cobertura.

Documentos base para empresa:

- NIT.
- Certificado de camara de comercio vigente.
- Documento del representante legal.

Documentos adicionales para independientes:

- RUT actualizado.
- Declaracion de renta o certificacion de ingresos.
- Contrato de prestacion de servicios cuando exista relacion contractual.

Buenas practicas:

- No procesar afiliaciones con documentos vencidos o ilegibles.
- Mantener trazabilidad de quien cargo y valido cada soporte.
