# Afiliacion de trabajadores independientes

Para afiliar a un trabajador independiente se requiere, como base operativa:

- Cedula de ciudadania.
- RUT actualizado.
- Certificacion o soporte de ingresos recientes.
- Contrato de prestacion de servicios, cuando aplique.

Reglas operativas:

- La cotizacion se liquida sobre una base minima de un salario minimo legal mensual vigente.
- El pago ordinario debe realizarse dentro de los plazos definidos para aportes al sistema.
- El formulario de afiliacion debe quedar diligenciado y firmado antes de activar la cobertura.

Controles sugeridos:

- Validar consistencia entre ingresos declarados y soporte documental.
- Confirmar que el tipo de cotizante corresponda al perfil del afiliado.
- Revisar que el primer pago quede conciliado antes de cerrar el caso.
