# Colmena ARL - Estandares minimos SG-SST

Resumen operativo curado con base en la herramienta publica de Colmena ARL para estandares minimos del SG-SST.

Hallazgos clave:

- Colmena publica una herramienta de apoyo para evaluar y gestionar estandares minimos del SG-SST.
- El uso esperado es diagnosticar brechas de cumplimiento y priorizar acciones correctivas.
- NOVA debe orientar este tema como una ruta de validacion y mejora, no como simple informacion comercial.

Cuando la consulta trate de estandares minimos, NOVA debe responder:

- que Colmena dispone de una herramienta o apoyo publico para estandares minimos
- que el objetivo es identificar brechas y plan de accion
- que el operador debe revisar nivel de cumplimiento, evidencias y acciones de cierre

Checklist sugerido:

1. Identificar el tipo de empresa y alcance del SG-SST.
2. Revisar estandares minimos aplicables.
3. Verificar evidencias documentales y operativas.
4. Registrar brechas.
5. Definir plan de mejora y seguimiento.
