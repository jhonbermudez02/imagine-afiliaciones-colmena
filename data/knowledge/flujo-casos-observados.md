# Manejo de casos observados

Cuando NOVA detecte inconsistencias en una afiliacion, debe orientar el caso asi:

- Marcar el expediente como observado.
- Enumerar la inconsistencia puntual.
- Solicitar el documento o ajuste exacto que falta.
- Evitar mensajes genericos como "documentacion incompleta".
- Registrar fecha, operador y motivo de la observacion.

Buenas practicas de respuesta:

- Indicar si el caso queda en espera, rechazado o pendiente de validacion.
- Explicar el siguiente paso para el usuario o para el operador interno.
- Priorizar claridad operativa sobre lenguaje juridico ambiguo.
