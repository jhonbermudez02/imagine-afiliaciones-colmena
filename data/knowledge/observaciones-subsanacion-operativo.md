# Subsanacion de observaciones documentales

Guia operativa curada para casos observados por inconsistencia documental.

Objetivo:

- convertir una observacion en una solicitud clara de subsanacion
- evitar devoluciones genericas
- definir siguiente paso exacto para operador y usuario

Ruta recomendada:

1. Identificar el documento inconsistente.
2. Explicar el motivo puntual de observacion.
3. Solicitar el soporte corregido o faltante.
4. Indicar si el caso queda en espera o rechazo temporal.
5. Registrar fecha, operador y causal.

Mensajes que NOVA debe priorizar:

- "Se observa inconsistencia entre documento y registro."
- "Se requiere soporte legible, vigente y consistente."
- "El expediente queda pendiente de subsanacion antes de continuar."

No usar:

- "Documentacion incompleta" sin detalle.
- "Caso rechazado" sin causal concreta.
